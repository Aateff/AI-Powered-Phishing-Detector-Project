# AI-Powered Phishing Detector

## Overview

The AI-Powered Phishing Detector is a machine learning project designed to detect phishing emails by analyzing email content and characteristics. The goal is to improve cybersecurity by automatically classifying emails as legitimate or phishing using artificial intelligence and natural language processing techniques.

This project demonstrates the complete machine learning pipeline, including:

- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Phishing email prediction
- Project documentation and presentation

---

## Project Objectives

- Detect phishing emails using machine learning.
- Reduce the risk of phishing attacks through automated classification.
- Explore Natural Language Processing (NLP) techniques for email analysis.
- Evaluate different machine learning algorithms for phishing detection.

---

## Features

- Email preprocessing and cleaning
- Feature extraction
- Spam/Phishing dataset analysis
- Machine learning model training
- Prediction of phishing emails
- Performance evaluation using classification metrics

## Dataset

This project utilizes the **SpamAssassin dataset** for training and evaluation.

Dataset included:

- `completeSpamAssassin.csv`

The dataset contains email samples labeled as phishing/spam or legitimate (ham).

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/AI-Powered-Phishing-Detector-Project.git
```

Navigate to the project folder:

```bash
cd AI-Powered-Phishing-Detector-Project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

If a requirements file is not available, install the required libraries manually:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn nltk
```
